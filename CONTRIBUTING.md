# Contributing

Thank you for improving Yggaro Lite. By contributing, you agree that your contribution is distributed under the repository's FSL-1.1-ALv2 licence and its future licence terms.

1. Open an issue for non-trivial changes before investing substantial work.
2. Never put vulnerabilities, credentials, personal data or customer content in a public issue or pull request. Use `SECURITY.md` for vulnerabilities.
3. Branch from the current default branch and keep the change focused.
4. Run `go test ./... -race`, `go vet ./...` and relevant UI/build checks.
5. Update public documentation, changelog and migration notes when behaviour changes.
6. In the pull request explain why, what changed, tests, security/data impact, compatibility and rollback.

Commits and pull requests use English. Generated files and dependency updates must identify their source. A contribution may be declined when it expands product scope, weakens a guardrail, lacks tests or cannot be maintained.
